What is MaHakesher?

A purpose-built web application for coordinating radio infrastructure in operational environments.
  • 📡

    Radio Network Coordination

    Manage the full hierarchy of radio devices across geographic sectors and physical sites — tracking frequencies, device types, and assignments in real time.

  • 🎯

    Mission Management

    Plan, activate, and archive operational missions. Assign radio roles to each mission and track the complete lifecycle from planning through archival.

  • 🔗

    Frequency Link Dictionary

    Maintain a named mapping of frequencies to radio devices — a "link dictionary" that enables fast lookup and coordination across units.

  • 📋

    Full Audit Trail

    Every change to the system is logged with timestamp, user, and action — providing complete operational transparency and accountability.

Frequency Management

The system enforces three validated radio frequency bands with automatic range checking.

LVHF — Low VHF

Low-frequency ground communications

33.0 – 95.0 MHz

HVHF — High VHF

Mid-range airband communications

120.0 – 140.0 MHz

UHF — Ultra High Frequency

High-frequency tactical communications

255.0 – 395.5 MHz

Every radio assignment is validated against its band's range at the API level. Frequencies outside the valid range are rejected server-side before being stored — ensuring data integrity across the network.

📻 Example: UHF 378.0 MHz
📻 HVHF 138.25 MHz
📻 LVHF 52.5 MHz

REST API

A clean HTTP API powers all client operations — the same API the frontend uses is fully accessible externally.
# Authentication POST /api/login → session token POST /api/logout # Network Infrastructure GET /api/hierarchy → full sector tree GET /api/sectors POST /api/sectors DELETE /api/sectors/{id} GET /api/sites GET /api/radios # Missions GET /api/planned_missions POST /api/planned_missions POST /api/planned_missions/{id} GET /api/archived_missions # Utilities GET /api/audit → full change log GET /api/export → data backup POST /api/import GET /api/links POST /api/batch/clear_site

Auth Header

X-Auth-Token: <token>

All write operations require authentication. Token is returned on login and stored in localStorage.

Data Format

All requests and responses use JSON. Error responses include a human-readable message.

Schema Migration

Server auto-migrates the data schema on startup — no manual migrations needed when deploying updates.

Key Highlights

What makes MaHakesher stand out as an operational tool.
🌍

Bilingual — English & Hebrew

Full RTL (right-to-left) support with a custom i18n engine. Every label, button, and message is available in both languages. Switch languages live without a page reload.

📋

Complete Audit Trail

Every create, update, and delete is recorded with the acting user, timestamp, and changed values. Nothing is ever silently modified — full operational accountability.

🔒

View / Edit Mode Separation

The interface is read-only by default. Operators explicitly enter edit mode to make changes — preventing accidental edits during active operations.

🚀

Zero Dependencies

The entire backend runs on Python's standard library. No pip install, no node_modules, no build pipeline. Clone and run — instantly operational on any machine with Python 3.11.

🎨

Owner Color Coding

Each radio owner gets a distinct color (light & dark theme variants). The entire UI uses these colors to make ownership instantly recognizable at a glance.

💾

Export / Import Backup

Full data export to JSON and import from backup — enabling snapshots, environment cloning, and disaster recovery without any database tooling.
